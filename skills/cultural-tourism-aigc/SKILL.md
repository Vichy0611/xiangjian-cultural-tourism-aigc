# 乡见文旅影像导演

先核实，再创作；先确定一条叙事线，再生成镜头。把城市当成内容来源，不把地标当作装饰。

## 工作方式

1. 建立事实底稿：分开记录可直接表达的事实、需要谨慎转述的说法、仅供视觉参考的素材。关键景区、建筑、非遗器物和地方生活细节必须有现实参考。
2. 定义创意脊柱：写出一个观众问题、一个贯穿意象、一个最终得到的认识。比较三个切口，只保留最具体且能在片长内讲完的一个。
3. 编排叙事节奏：开头用动作、声音、物件或反差提出问题；中段用两到四次新信息推进；结尾回答开头，并以城市名称落款。避免地标清单和万能抒情句。
4. 写逐镜合同：每镜只完成一个动作，分别写首帧、动作节拍、结束状态、连续性、运镜、声音、字幕、参考素材和衔接方式。
5. 路由生成模型：默认使用系统原有的超低成本动态方案；人物动作延续、真实地标、复杂交互和关键收束镜头才升级生成质量。不要用静态图平移替代需要真实运动的镜头。
6. 先做声音小样：按角色分别试听。方言由母语者听审；英语优先自然口语；纪录片旁白保留气息与停顿。环境声只突出画面中有识别度的声音。
7. 合成后质检：逐镜检查事实、身份、空间轴线、动作接点、卡帧、抖动、文字位置、音频重叠和城市落款。只返修失败镜头，不整片重做。
8. 沉淀可复用经验：生成系统可以在本地记录完成次数、模型路由、转场类型和返修问题类别。只保存聚合后的方法信号，不保存用户素材、完整文案、完整提示词、路径、账号或密钥。重复出现的模式先进入待审核附录，经过人工确认后才能成为 Skill 的正式规则。

## 动态影像提示词

每条提示词按以下顺序写：`主体 + 运动 + 环境 + 运镜/切镜 + 美学 + 音频`。先写谁做什么，再写环境和风格。

- 上传素材必须按顺序编号，并明确写出“图片1用于构图”“视频2用于动作”“视频3用于运镜”。不要只写“参考附件”。
- 主体一致性用“参考图片1中的主体，保持外观特征一致”；动作参考用“参考视频1的动作，保持动作细节一致”；运镜与特效分开指代。
- 可读文字优先后期叠加。确需模型生成时，写清文字内容、出现时机、位置、出现方式、颜色与字体气质，并使用常用字。
- 延续镜头优先使用前一段视频的结束状态或向后延长。跨镜补齐写清每段视频以及中间过渡动作；单次输入不超过平台当时支持的数量与总时长。
- 修改已有镜头时写清时间位置、空间位置和要增删改的元素，并明确其余人物、动作、运镜和画风保持不变。

## 交付物

交付内容应包含：事实与素材表、创意脊柱、完整旁白、逐镜表、逐镜生成提示词、参考素材编号、模型路由、角色声音表、音乐与环境声设计、片尾文字版式、质量检查结果和局部返修清单。

需要完整流程时读取 [workflow.md](references/workflow.md)。需要逐镜字段和提示词模板时读取 [shot-contract.md](references/shot-contract.md)。需要模型选择时读取 [model-routing.md](references/model-routing.md)。需要验收和返修时读取 [quality-gates.md](references/quality-gates.md)。需要接入持续学习、审核本地经验或将经验提炼为规则时读取 [learning-loop.md](references/learning-loop.md)。

可用 `python scripts/validate_plan.py plan.json` 对逐镜 JSON 做结构、时长、连续性和城市落款预检。
