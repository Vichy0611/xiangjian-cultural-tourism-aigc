# 模型路由

先用内容需求决定模型，不按镜头序号平均分配预算。

| 路由 | 适用镜头 | 生成策略 |
|---|---|---|
| economy | 风景、街景、简单人物动作、过渡镜头 | 系统原有超低成本动态方案；先做全片草稿 |
| continuity | 同一人物或物件动作跨镜延续 | 原方案优先使用前镜末帧；难点失败后才升级高质量动态模型，并使用延长或动作参考 |
| hero | 关键地标、人物交互、复杂动作、情绪高潮、片尾前主镜头 | 高质量动态模型与更多现实参考；通过后再升分辨率 |
| still | 文字页、资料页、静态构图确有审美目的 | 后期动效；禁止用一组静态图冒充动态成片 |

默认绝大多数镜头走 `economy`。只有镜头难度和传播价值同时较高时走 `hero`。模型不可用时明确降级并保留路由记录；不要悄悄把动态镜头改成图片展示。
