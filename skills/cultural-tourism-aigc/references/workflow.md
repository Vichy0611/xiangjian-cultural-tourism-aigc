# 文旅视频生成工作流

## 0. 生产约束

冻结目的地、受众、语言、时长、画幅、传播场景、真实性模式、预算和交付平台。先确认哪些镜头必须是真实地标，哪些可以做意象表达。

## 1. 资料与素材

- 优先政府、景区、博物馆、非遗名录和权威机构资料。
- 给每条事实和参考图编号。事实来源与视觉参考分开记录。
- 真实地标至少准备一张能辨认空间关系的参考图；人物连续性准备正面、侧面和服饰参考；动作难点准备短视频参考。
- 不能核实的年份、工序、开放信息和“全国唯一”等表述直接删掉或收窄。

## 2. 创意脊柱

内部提出三个不同切口，按地方独特性、视觉可拍性、30–60 秒可解释性和情绪余韵评分。最终输出故事问题、贯穿意象、信息承诺和结尾回答。开头提出的问题必须能由现有资料回答；结尾先回答问题，再落城市。

## 3. 逐镜设计

每镜必须新增信息。首帧只写可见状态，动作写前中后三段，结束状态供下一镜接续。相邻镜头优先使用动作匹配、方向匹配、声音桥、形状匹配或光色匹配。跨地点且无法匹配时使用短溶接或有意义的过渡镜头。

## 4. 生成顺序

1. 先生成或选定参考首帧。
2. 用系统原有超低成本方案生成全片动态草稿，验证故事、运动量与节奏。
3. 只将关键地标、人物交互、连续动作难点和片尾前核心镜头升级到高质量动态模型。
4. 连续动作从前镜最后一帧或原视频延长，避免重新抽卡。
5. 文字、地点、片名和城市落款统一在后期排版。

## 5. 声音

先确定说话者，再选音色。不同角色使用不同音色；同一叙述者可在正式成片中混合相近音色，但要统一年龄感、气息、语速和空间混响。环境声按“特色声在前、普通底噪在后”混音：窑火、桨声、潮声、钟声可以突出，持续风噪和宽频噪声压低。音乐给对白让位，并在转场处提供节拍连接。

## 6. 合成与返修

先检查无声画面，再检查人声，再检查全混音。失败镜头按问题类型返修：身份或地标错误重做首帧；动作断裂用延长或动作参考；运镜抖动改固定机位；字幕错误由后期修复；环境声过大只重混音。不得因为一个镜头失败而重新生成已通过镜头。
