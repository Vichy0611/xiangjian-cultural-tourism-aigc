# 逐镜合同

每镜记录以下字段：

- `scene_desc`：首帧中的主体、环境、景别、光线和构图。
- `action`：单一连续动作的开始、发展和结束。
- `end_state`：最后一帧可见的姿态、位置和视线。
- `continuity`：人物、服饰、器物、左右方向、空间轴线、天气和色温。
- `camera`：固定、缓推、缓拉、左移、右移之一。
- `transition`：动作匹配、声音桥、形状匹配、光色匹配、柔和溶接或明确切点。
- `reference_plan`：图片和视频编号分别锁定什么。
- `soundscape`：画面内可见声源与远近层次。
- `speaker`、`performance`：说话者、交流意图、重音和停顿。
- `generation_route`：`economy`、`continuity`、`hero` 或 `auto`。
- `screen_location`、`screen_title`、`screen_detail`：只用于后期叠加。

动态生成模板：

```text
一个连续的{时长}秒镜头。图片1是本镜真实首帧和构图依据，不重新布景。
主体与动作：{主体}；{动作节拍}。
环境与美学：{环境、时段、色温、质感}。
摄影机：{单一运镜}，地平线稳定，无手持抖动和突然变焦。
结束状态：{最后一帧}。
连续性：{身份、器物、轴线和方向}。
衔接：{transition}。
音频：{soundscape}。禁止旁白、歌词和无来源叫卖。
画面内不生成标题、字幕、标牌或水印。
```

多模态参考模板：

```text
参考视频1的动作细节；参考视频2的运镜；参考图片1中的人物外观；参考图片2的真实地标结构。生成本镜内容，保持各参考对象的指定特征一致，不混用参考作用。
```
